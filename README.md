# Competitor Price Monitor

Projeto desenvolvido em Python para monitorar preços de materiais de construção em sites concorrentes.

## Tecnologias

- Python
- Requests
- BeautifulSoup
- Pandas
- Git/GitHub

## Objetivos

- Coletar preços automaticamente
- Armazenar histórico
- Gerar relatórios
- Comparar preços entre concorrentes
